展示我的贪吃蛇

2026-11-15 admin #html

在 GitHub 主页养一条赛博贪吃蛇：这是我的最终成果

缘起：一眼心动的赛博宠物

最近在逛一些极客大佬的主页时，无意间发现他们的 GitHub 贡献图不是静态的绿格子，而是一条像素风的贪吃蛇，在欢快地“吃”着那些代表代码提交的方块。

这个动画简直长在了我的审美点上。既然别人能有，那我也得给自己安排一条！于是，说干就干。

原理：它是怎么活起来的？

其实这并不复杂，不需要你自己去写复杂的动画代码。它的核心是 GitHub Actions 提供的自动化能力：

  1. 定时运行：机器人每天定时去抓取你的 GitHub 贡献数据。
  2. 路径计算：用算法算出从起点到所有绿格子的一条最优路径。
  3. 生成动画：将路径渲染成一张包含 CSS 动画的 SVG 图片，并自动推送到仓库的 output 分支。

配置过程：只留精华代码

直接在我的同名仓库（wng409/wng409）里新建一个 .github/workflows/snake.yml 文件，贴入下面这段极其优雅的配置，让它每 12 小时（半天）跑一次，保持最新鲜的“食物”：

name: Generate Snake

on:
  schedule:
    - cron: "0 */12 * * *" # 每 12 小时跑一次
  workflow_dispatch:       # 允许手动触发
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake SVG
        uses: Platane/snk@v3
        with:
          github_user_name: wng409
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

(注意：记得去仓库的 Settings -> Actions -> General 里，把权限改成 Read and write permissions，这样机器人才能帮你推图片。)

成果展示：直接上效果

代码跑绿之后，output 分支里就静静躺着两张生成好的 SVG 图片了。

为了让它在我的主页（点击跳转）上不仅好看，还能完美适应访客的深浅色模式，我用了一段 <picture> 标签，并且为了保证加载速度，我挂上了一个国内极速的镜像加速链接：

</picture>

刷新主页，大功告成！

白天它是青翠的绿色方块蛇，夜晚模式它会自动变成暗黑发光版。每次提交代码，这颗绿格子就会变成它的食物，看着它一天天变长，这种自动化的成就感真的让人上头。

如果你也有强迫症，想给自己的代码主页加点极客浪漫，赶紧去建个 Actions 跑起来吧！
